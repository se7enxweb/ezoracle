# ezoracle 2.3.14

Changes since 2.3.13.

- Added: `[QuotedIdentifierSettings] TypeColumnNames[]` in settings/ezoracle.ini, for column names that are also
  Oracle data types, such as the `number` column of the help desk's ticketsystem_ticket. Such a name cannot go into
  `ColumnNames[]`: the driver would quote it everywhere, also where NUMBER is the type (`NUMBER(11,0)` in DDL,
  `DECLARE m NUMBER;` in PL/SQL, `CAST( x AS NUMBER )`). A name in `TypeColumnNames[]` is quoted like one in
  `ColumnNames[]`, but only in SELECT, INSERT, UPDATE, DELETE, MERGE and WITH statements, and never before "(" or
  after AS; a bind variable named after one gets a prefix. The schema handler already quoted such a column in its
  own DDL. The file ships no empty `TypeColumnNames[]` line, so the names an extension adds in its own
  settings/ezoracle.ini.append.php are kept whatever the order of the extensions.

Tests without a database for the type names, the statements where the word is the type, and the bind variables.

Upgrading: composer update. Nothing to do in the database. ticketsystem 1.1.0 and later need this version on Oracle;
it lists `number` in its own ezoracle.ini.append.php.
