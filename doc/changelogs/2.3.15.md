# ezoracle 2.3.15

Changes since 2.3.14.

- Fixed: Comparisons with the empty string run on Oracle, also on CLOB columns. Oracle stores '' as NULL, so
  `column <> ''` and `column = ''` were never true there, and on a CLOB column they failed with ORA-22848 "cannot use
  CLOB type as comparison key" (the reference check of Exponential Layouts and the AI dashboard did). The driver
  now sends `column <> ''` and `column != ''` as `IS NOT NULL`, and `column = ''` after WHERE, AND, OR, ON, WHEN or a
  bracket as `IS NULL`; assignments, string literals, quoted identifiers and comments are left as they are.

Tests without a database: tests/eZOracleEmptyStringComparisonTest.php.

Upgrading: composer update. Nothing to do in the database.
